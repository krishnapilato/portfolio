The boring parts, done properly.

A Spring Boot service that already takes care of accounts, sign-in and transactional email. It is tested, observable and ready to deploy, so the next project can start with the part that is actually new.

Explore the API Read the source →

What it covers

Accounts
Sign-up with email verification, roles, lockout after repeated failures, and admin tools that refuse to remove the last administrator.
Sessions
Short-lived access tokens. Refresh tokens rotate on every use, and replaying an old one revokes the whole chain.
Email
A transactional outbox: messages are saved with the change that caused them, then delivered with retries, safely across instances.
Operations
Health checks for orchestrators, Prometheus metrics and structured logs where every line carries its request id.
Quality
The build fails on any compiler warning, and the tests are graded by mutation testing, not just coverage.
